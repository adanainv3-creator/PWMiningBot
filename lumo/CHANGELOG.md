# Changelog

- Initial release

- Now Playing screen with rotating disc, waveform visualizer, full controls

- 5-band Equalizer with presets
- Sleep Timer
- Settings screen
- About screen
- Bottom navigation with Mini Player bar
- Glassmorphism UI, Material 3, neon green / mat black theme
- GitHub Actions CI/CD with lint, tests, debug build, and signed release
